# Wecamp training

Welcome to the **wecamp-training** repository! Đây là nơi lưu trữ mã nguồn, bài tập, và tài liệu học tập trong suốt quá trình tham gia khoá học Wecamp (Batch 11).

## Giới thiệu (Introduction)

Dự án này được tạo ra với mục đích thực hành và lưu lại các kiến thức học được tại Wecamp.

## Công nghệ sử dụng (Technologies)

- HTML5 / CSS3 / JavaScript
- React, Node.js, v.v.

## Hướng dẫn chạy dự án (How to run)

1. Clone repository này về máy:
   ```bash
   git clone <link-repo-cua-ban>
   ```
2. Mở thư mục dự án bằng VSCode hoặc Editor của bạn.
3. Chạy file bằng Live Server (đối với HTML) hoặc cài đặt các thư viện cần thiết.
